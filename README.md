# js-voice-notes-app

## brief description
js-voice-notes-app is a HTML5, CSS3, and JavaScript application that allows users to record and save voice notes. It uses SpeechRecognition API to capture voice input and Speech Synthesis Utterance to convert speech to audio. It allows users to record and transcribe voice notes, making it simple to capture thoughts, ideas, and meetings. It features the CRUD functionality to create, read, update, and delete voice notes, with SweetAlert2 for notification messages.

## features
- Record and save voice notes
- Transcribe voice notes
- CRUD functionality
- Notification messages
- Responsive design
